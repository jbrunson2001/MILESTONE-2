Key Concepts

This page explains the main words that are used in this project. These words connect to HTML, CSS, JavaScript, and how browsers display web pages.

  1. Browser: software used to access websites. Examples include Chrome, Firefox, Safari, and Edge.
  2. Browser engine: the part of the browser that renders pages and displays the final result.
  3. Rendering: the process of turning code into the visual page that users see.
  4. HTML: the markup language used for page structure.
  5. CSS: the language used for style and layout.
  6. JavaScript: the language used for actions and interactivity.
  7. Web standards: rules that help websites work in different browsers.

How the parts work together

HTML gives the page its basic structure. CSS changes how the page looks. JavaScript can make the page respond to the user. The browser engine takes those parts and displays them in the browser window.

Simple example

If a web page has a heading, the HTML says it is a heading. The CSS might make the heading gold and bold. The browser engine is what actually draws that heading on the screen.

Why standards are helpful

Web standards are helpful because people use different browsers and devices. Standards help developers make websites that work more consistently. Without standards, a website might work in one browser but not work correctly in another browser.
